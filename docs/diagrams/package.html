go-observability 包图

按层分组 · 依赖方向自上而下 · 核心零依赖

包图 (Package Diagram) — 结构性图形。按模块/命名空间分组并展示依赖。

分层边界

  • • 集成层 middleware 依赖核心层 log/ + errs
  • • 核心层零 OTel：log/ 只依赖 errs
  • • 映射层 internal/ 只在 logwriter/*、telemetry 侧使用

装配与出口

  • • telemetry 统一装配 Trace / Metric / Log Provider
  • • logwriter/file、stdout、otlp 共享同一事件模型
  • • 出口可替换：业务埋点不重写

  • • 01_quickstart ~ 17_layered_span：逐能力演示
