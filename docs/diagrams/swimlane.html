go-observability 泳道图 — 一次 HTTP 请求全链路

客户端 → Gin 中间件链 → 业务 → Logger 治理管线 → 出口

泳道图 (Swimlane Diagram) — 行为性图形。跨组件/角色职责流程（活动图变体）。

中间件链

  • • TraceMiddleware：链路注入/提取 + 分层 span
  • • AccessLog：每请求一条 AccessEvent
  • • Security/AuditGuard：认证/授权判定自动留痕
  • • ErrResp/Recover：错误收口 + panic 兜底

治理管线

  • • Logger.Emit：采样 → 脱敏 → 归一化 → 写出
  • • TraceExtractor 从 ctx 补全链路标识
  • • 事件类型由 type 粗分类承载

出口

  • • file：JSONL 扁平列，便于 grep/jq 检索
  • • otlp：OTLP gRPC 到 Collector / LGTM
  • • stdout：本地开发诊断
