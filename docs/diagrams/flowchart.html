go-observability 流程图 — 错误收口

middleware/httperr 契约 + Gin/net-http 适配 · 错误事件唯一 · 安全/审计并存

流程图 (Flowchart) — 行为性图形。展示主流程与关键分支。

错误判定

  • • 非 AppError → UNKNOWN_ERROR 兜底
  • • validation / business → 预期拒绝，正常响应路径
  • • system → SYS_ERROR，告警与重试评估

事件写出

  • • ErrorEvent 每请求唯一（错误出口唯一）
  • • InputGuard 注入 Security/Audit，与错误事件并存
  • • 共享同一 ctx：trace/span 自动关联

收口契约

  • • StatusForError：Kind → HTTP 状态码
  • • ResponseBody：system 响应不泄露内部细节
  • • Abort(nil) 兜底，与 recover 不双写
