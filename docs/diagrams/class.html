go-observability 类图（核心类型）

log/ 事件核心 · errs 错误模型 · logwriter 写出层 · telemetry 装配

类图 (Class Diagram) — 结构性图形。展示核心类/接口及其实现、组合与依赖关系。

log/ 事件核心

  • • 六类事件 embed EventMetadata + 各自 Data 载荷
  • • 事件实现 EventPayload（EventType + Attrs）
  • • Logger 组合 Sampler / Masker / Writer / TraceExtractor
  • • 构造后只读，Writer 承担并发契约

errs 错误模型

  • • AppError：Kind() / ErrorType() / ErrCode()
  • • SystemError 自动采集堆栈，BusinessError 业务拒绝
  • • log/error_project 沿错误链投影为 ErrorEvent
  • • ErrorType 为 OTel/gRPC canonical code（低基数）

写出与装配

  • • logwriter/file、stdout、otlp 实现 ManagedWriter
  • • telemetry.Runtime.NewLogWriter 按 LogConfig.Output 选择出口
  • • internal/attrkv 负责 OTel LogRecord 顶层字段映射
