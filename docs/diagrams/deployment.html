部署图 (Deployment Diagram) — 结构性图形。展示物理节点、中间件与通信协议。

进程内装配

  • • telemetry.Runtime 创建独立 Trace / Metric / Log Provider
  • • 不安装全局状态；InstallGlobal 显式安装并返回幂等恢复
  • • Shutdown 顺序：先 log 再 metric 后 trace

本地出口

  • • LogConfig.Output=file → JSONL 追加写（含轮转）
  • • file/stdout 注入同一份 Resource metadata
  • • 零配置本地可跑：NewFileRuntime 预设

OTLP 链路

  • • 批量导出间隔：trace 5s / metric 15s / log 1s（SDK 侧）
  • • Collector batch 二次凑批；tail_sampling 按错误/概率保留
  • • 头部采样 SampleRatio=0.1：未选中 trace 无法恢复
