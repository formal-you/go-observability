go-observability 系统架构

slog 与 OpenTelemetry 之间的语义层 · 事件类型稳定 · 字段来源明确 · 三信号统一装配

架构图 (Architecture Diagram) — 结构性图形。描述系统顶层组件、连接关系与依赖方向。

分层与依赖方向

  • • log/ 只依赖标准库 + errs（AppError 消费）
  • • middleware 依赖 log/ + errs
  • • logwriter/*、telemetry 依赖 log/ + internal/*
  • • OTel SDK 只出现在 internal/attrkv、logwriter/*、telemetry、middleware/*

双投影

  • • file/stdout：扁平 JSON 列，保留 event.name / app.*
  • • OTLP：severity / EventName / timestamp 提升为 LogRecord 顶层
  • • 业务埋点不因出口变化而重写

治理管线

  • • Logger.Emit：Sampler → Masker → Normalize → Writer
  • • TraceExtractor 从 ctx 补全 trace_id / span_id
  • • 批量导出间隔由 telemetry.Config 控制（trace 5s / metric 15s / log 1s）
