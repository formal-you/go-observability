包级组件与依赖关系 · 核心零依赖 · 出口可替换

组件图 (Component Diagram) — 结构性图形。展示系统组件及其依赖关系。

依赖方向

  • • middleware 依赖 log/ + errs
  • • log/ 只依赖 errs（AppError 接口）
  • • logwriter/otlp 依赖 internal/attrkv 做顶层字段映射
  • • telemetry 依赖 internal/otlpendpoint 校验 endpoint

集成组件

  • • middleware/httperr 是错误收口契约核心
  • • gin / http / grpc / kratos 为框架适配器
  • • middleware/otelutil 提供链路注入/提取与分层 span

出口链路

  • • 同一事件可同时输出 JSONL / stdout / OTLP
  • • OTLP gRPC → OTel Collector → LGTM
  • • example/mall 展示 Gin 全链路参考栈
