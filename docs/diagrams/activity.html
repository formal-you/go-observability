从 Config 到三信号 Provider 的装配与失败回滚

活动图 (Activity Diagram) — 行为性图形。展示过程的流程与分支。

装配流程

  • • 先校验 Config，再构建 Resource
  • • Trace / Metric / Log Provider 独立装配
  • • 构造中途失败逆序回滚已取得资源

出口选择

  • • LogConfig.Output：file / otlp / stdout / none
  • • file/stdout Writer 由 NewLogWriter 延迟创建
  • • Enabled=false 返回仅 LogConfig 的禁用 Runtime

预设

  • • NewFileRuntime：Trace=local / Metric=none / Log=file
  • • NewOTLPRuntime：全 OTLP 档位
  • • 自定义采样/批量/队列/轮转用 NewRuntime + Config
