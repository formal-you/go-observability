go-observability 序列图 — Logger.Emit 治理管线

一次类型化事件从埋点到双投影出口的完整调用链

序列图 (Sequence Diagram) — 行为性图形。按时间顺序展示对象间交互。

治理管线

  • • Emit → SampleEvent → Mask → normalize → Write
  • • 采样器接口：Sampler / EventTypeSampler
  • • 高价值结果（failed/error/blocked/denied）强制保留

写出

  • • Writer 位于治理管线末端，看到已完成采样/脱敏的事件
  • • file / stdout / otlp 三种 ManagedWriter
  • • 写入错误走 ErrorHandler，不冒泡给业务

链路

  • • TraceExtractor 从 ctx 补全 trace_id / span_id
  • • 事件未显式携带链路时自动补全
  • • 核心包零 OTel 依赖，适配器由集成层注入
