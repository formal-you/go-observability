go-observability 用例图

三类参与者 × 12 项核心能力

用例图 (Use Case Diagram) — 行为性图形。从用户/运维/审计角度展示系统功能。

应用开发者

  • • 六类类型化事件埋点，不写自由字符串
  • • event.name / error.code / error.type 注册表校验
  • • 错误投影：普通 error / %w 链 / 值指针错误

治理能力

  • • 采样：ResultKeep / EventTypeKeep / EventKeep
  • • 脱敏：FieldMasker 递归覆盖 map / slice / LogValuer
  • • 双投影：file/stdout 扁平列 + OTLP 顶层字段

运维 / 审计

  • • Security/Audit 中间件自动写安全与审计事件
  • • 三信号统一装配 + 关闭顺序治理
  • • LGTM 本地栈查看，JSONL 直接检索
